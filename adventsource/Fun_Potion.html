How it is built

The glass, the potions (one oklch() formula turns a colour number into a potion), the pour, the slosh and the cheer are plain CSS. Reactive CSS adds the interaction, with no application JavaScript:

  • The board is 24 slot state()s and six heights. A tap lifts a tube, and a second tap pours.
  • Each pour is one :on(click) rule for its situation (from, to, both heights), gated by :when() conditions that compare states (--c12 == --c34, !=, and, or). It moves the whole same-coloured run that fits, with set(), in one go: 900 rules, generated.
  • Every pour records where it came from and went, so :changed() plays the tip-and-pour animation.
  • A six-tube :when() condition detects the win. Restart and Next are click rules that set up a level.
